# GITHUB-CLAUDE-SKILLS

Claude skills for writing software engineering documents.

| File | Purpose |
| --- | --- |
| `foom-sds-writer.skill` | Writes a Software Design Specification (SDS) |
| `srs-proposal-writer.skill` | Writes a Software Requirements Specification (SRS) and project proposals |

The `.zip` files are packaged copies of the same skills.

## Credit and attribution

**All credit for the document structures, templates and requirements belongs to the original ISO/IEC/IEEE standards and their authors.** This repository does not claim ownership of them, and it does not reproduce the standards themselves.

**The only original work here is the Claude skills.** These are the skill files, which instruct Claude how to apply those standards and templates.

If you need the authoritative definition of any document structure, use the official standards, not these skills.
